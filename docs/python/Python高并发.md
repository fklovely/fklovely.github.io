# Python性能

说起主流编程语言的性能，我们大概会条件反射地想到，c/c++最快，python最慢，这可以说是深入人心。但是我们得透过现象看本质，得从语言本身的机制入手，才能得到答案。

## Python的全局解释器锁(GIL)

Python在CPU密集型的任务中表现显著的慢，究其原因是因为Python的主流实现CPython中，存在着全局解释器锁(GIL)。GIL保证同一个解释器中的同一时刻，只能有一个线程执行Python字节码。因此当面对CPU密集型任务时，一个线程执行，另一个线程就只能干等，这毫无疑问会
