# 并发
第一次接触并发还是在学习操作系统的时候，那时候还在大三上学期呢，人生中比较幸福的一段时光。

## 并发vs并行
并发指的是在一段时间内，多个任务交替执行，看起来就像同时运行一样，而并行是真正的同时运行。
假如说现在有3个线程，其中1个用完CPU后开始等待IO，那么其他两个线程即可开始运行自己的任务，由于IO时间一般比较长，因此并行会看起来像是同时运行。而并行需要的是多个CPU核心，每个核心各自独立运行，所以速度更快。
