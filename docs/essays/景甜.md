# 孙景事件有感

最近这个孙宇晨、景甜事件可谓是闹得沸沸扬扬。上周五一起床，打开手机，大学舍友就给我转发了pdf。当时我还没怎么仔细看，所以这篇文章拖到今天才写，就在刚刚我才看完pdf全文。

我首先不得不感慨孙宇晨真是真爱啊，毕竟能给景甜花这么多钱，按照女人们的标准，恐怕世界上没有几个比他更爱景甜的。花钱是一方面，孙宇晨时隔十几年，依然对景甜念念不忘，而仅仅是因为一张模糊的照片，这份执着，我也是很震惊。我不得不猜想，你孙割这么多年，努力奋斗赚刀乐，就是为了得到景甜，就是为了弥补青春年少时的遗憾，就是为了告诉那些所谓的大佬，你们能得到的女人我也可以。在这一点上，孙宇晨和景甜，李新野和郭菊阳可谓是非常相似。要不说人家能成功呢，我在这一点上，在复仇的心理上，还是差太多了。

从孙宇晨写的小作文来看，他和景甜之间基本没有太多的交流，全是人机对话、无效交流，毕竟一个是为了赚钱、一个是为了体验，我估计二者其实都没想过真和对方结婚。孙宇晨说自己没有哭，自己在等自己哭，这就对了，说明你孙割其实还没有入戏太深，不然也不会让Claude code给自己建议，找个只会顺从的模型骗自己得了。人真的能和一个与自己没有太多交流的人在一起甚至结婚吗？在以前包办婚姻的年代，这很好理解，在现代，做一个酒肉情侣，也挺好。只不过现实终究有醒来的日子，酒肉情侣最终也基本不会结婚，大学毕业，各奔东西。

孙割小作文中一个很有意思的点是，他说景甜的禁忌就是某个运动员的名字，其他前任都无所谓。这个运动员无非就是张继科，大家都知道。我觉得这说明景甜恰恰是真心爱过张继科的，禁忌就是害怕，人越是禁忌什么，就越是在意什么，越是在意自己的情绪会因为此产生大的波动，就越是害怕自己会回想过去的事情以及否定现实的自己。按照李新野的说法，景甜十几岁就委身大佬，尝到的只是金钱的滋味，不曾知道人世间还有叫做喜欢的东西，和张继科在一起之后，她一定觉得自己的灵魂都像是被净化了一样，不然也不会把张继科的名字纹在自己身上，不过为什么二人最后分开，这个就不得而知了。

令人难绷的是，胡锡进也下场了，本来这件事可能过几天就淡出大众视野了，胡师傅这波进场时机抓得不错。里面怒斥孙宇晨是丢全体中国男人的脸，大概意思就是追还彩礼可以，但是不能公开前女友的隐私。我承认他说的有一定道理，但是孙割就未必了。孙宇晨立刻写了一封回信，这个回信写得好啊，好就好在抓住了彩礼这个关键词，好就好在同化到了全中国所有的男人身上，好就好在让中国男人知道，我们都一样，无非是三万、三十万和三千万的区别。众所周知，彩礼一直是我国的一大焦点问题，一提到彩礼，评论区定是上蹿下跳，好不热闹。男人和女人，几乎不可避免地会在这个问题上起争论。一个再前卫、再宣称自己独立自主的中国女性，只要碰到彩礼问题，都会变成忠诚的、久经考验的保守主义战士，不管她是来自新兴的小红书、老牌的微博以及大本营豆瓣。在我的印象里，没有什么问题能让中国女性如此着急了，只要国家发了什么文件说要整治彩礼，她们立马会装模做样发个朋友圈宣布自己的生育主权。她们的胆子可谓是非常的大，大就大在敢公开吐槽贬低男人，大就大在敢将相关视频发给自己的男性朋友，她们就真的没有想过这会让自己的性魅力急剧下滑吗？毕竟在现代，无论多么嚣张的男人，都不会放肆地宣布自己是一个大男子主义者。因为大男子主义是保守落后的，而女权主义则是进步先进的。只不过二者在彩礼这件问题上非常的有默契，一个要，一个给，真是天作之合啊，这又何尝不是一种中国特色呢？这是辩证法的胜利。

好了，不要再吐槽我们的女同胞了，还是回到猢狲对话之中吧。胡锡进又写了一封回信，对于彩礼问题只说了一句现在很多彩礼都是可以追还回来的，令人大失所望，好没意思。不过胡锡进在文章的最后一句非常有意思啊，“等你回北京的时候，我们再好好谈谈”，这句话感觉不亚于我和zxc吵架，来一句“过年别走啊，回罗山再谈”，充满着威胁的意味，又给老登装到了。这可能也是老登的体面吧，其实这次回信两个人谈论的核心压根不在一个点上，胡锡进说的是不该抖落隐私，孙宇晨则视角大多了，一个是男性彩礼，一个是老登们的“体面”。屁股决定脑袋，这话用在胡锡进身上还算比较合适，如果是哪个女明星曝光渣男男友，就算涉及到了隐私，老胡肯定也是拍手称快，毕竟老登们其实就是那套大男子主义叙事，让让女人们怎么了。不同年代的人看待事物是天差地别的，孙宇晨的“体面”一文就很好地诠释了这一点，过去人们办事，靠的是人情关系，靠的是私人交情，说白了，没有关系的人，他是不把你当人的，因此我们可以看到，在过去的几十年里，出现了大量的冒名顶替上大学的，我身边亲戚就有这样的例子，最后也是托人找关系才保住。还有一个典型代表就是饭局，动不动就让人喝酒陪酒，丝毫不考虑别人的感受，饭局还有一个有意思的点是，总会有独立女性献殷勤，所谓最大限度地利用自己的女性魅力，历史的惯性，大概如此。我不知道这样的情况需要多久才能改变，可能就最近二十年，也可能五十年或者一百年，不过我相信最后中国会成为一个更加自由、平等的国家，到那时候，过往的一切唐宗宋祖、秦皇汉武，在太阳照耀的这片土地上，都会显得黯然失色。
