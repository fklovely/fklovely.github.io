# 真情令人温暖

一转眼国庆假期就结束了，假期里一个人在宿舍里玩艾尔登法环，偶尔和朋友们打瓦，倒也过得十分自在。之前我爸说国庆他可能会回家，昨天下午我要去吃饭前，一看微信，二十分钟前给我发消息说他在姥娘家，要不要打个视频。我说好，他说还在那，我就打了过去。

“这给，打视频打过来了，你瞧”，我爸对姥娘说。我看姥娘的脸，感觉她真的老了不少，她看见我的第一句话就是“小可，你看姥娘老不”，我沉默了两秒，我爸连忙说老啥呀，不老，还是那样。我听到那边还有小姨的声音，我爸刚好说你小姨、姨姥都在，你跟你姨姥聊几句，姨姥接过手机，我的手机上显出了一张很高兴的脸，姨姥也是又性情了，我也很高兴，看到亲人们真的就是会感觉幸福。没等到他开口，我直接说“王惯的保研保哪里去了呀，这都10月7号了，都结束了。”“好的没搞上，搞的浙江工商大学，本来想搞兰州大学的，后面搞鬼了。” 后面又是一些生活闲聊，我爸又让我和姥爷说几句话。我姥爷是那种刀子嘴豆腐心的角色，小时候经常听他说“养你们不如喂条狗，喂条狗还能摇摇尾巴”，现在看见他，总是笑咪咪的，这次也不例外。“你们啥时候放假啊？”，上了年纪的人，总是喜欢问这种令人苦笑不得的问题，我说过年放假。“你现在学习怎么样啊？”“就那样”，“你好好搞啊”，姥爷笑得更灿烂了。又说了没几句，我爸说:好，你也去吃饭，我们也吃饭了。我就挂掉了视频。

挂掉视频之后，我还是觉得很温暖，感觉心情都好了非常多，亲情就是有这样的力量。不止亲情，还有友情，归根结底还是一个“真”字，真诚、真挚永远都是这么令人感动。世间自有真情在啊，生活的一切困难、烦恼，在这些面前彷佛都不值一提，我想这也是交朋友乃至结婚生子的意义吧。
